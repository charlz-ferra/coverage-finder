# Coverage Finder

Coverage Finder помогает выбрать английскую книгу или субтитры под свой словарный запас. Приложение показывает, сколько слов знакомо, сколько предложений можно прочитать целиком и какие 20–40 лемм помогут понять больше реплик. Пользовательские файлы обрабатываются в браузере.

![Демо-библиотека, импорт словаря, подсветка слов и экспорт в Anki](docs/walkthrough.gif)

## Открыть готовое приложение

У владельца проекта есть [закрытая веб-версия Coverage Finder](https://coverage-finder-reading-lab.coolcroissant8.chatgpt.site).

В этой рабочей копии уже собрана папка `dist/`. В Windows дважды щёлкните [Open-Coverage-Finder.cmd](Open-Coverage-Finder.cmd). Он откроет приложение в браузере. Оставьте окно запуска открытым до конца работы. Лаунчер использует Python 3 или установленный в проекте Vite.

На другой платформе готовую сборку можно открыть через любой статический HTTP-сервер. Команда ниже запускает библиотеку по адресу [127.0.0.1:8765](http://127.0.0.1:8765/).

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Используйте тот же адрес и браузер при следующем запуске. IndexedDB привязана к адресу сайта, порту и профилю браузера. Между локальной и размещённой версиями библиотека переносится через JSON в настройках.

## Первая книга

1. Откройте демо-библиотеку из 14 литературных текстов. Первоначальный рейтинг использует 3 000 частотных лемм. Для «A Kind Brother» знакомы 99% слов и 85,7% предложений. Для отрывка «Pride and Prejudice» эти значения составляют 93,2% и 53,3%.
2. Нажмите **Загрузить словарь** и выберите CSV, TXT или текстовую выгрузку Anki. Проверьте колонку в предпросмотре. Альтернативный вход — **Пройти тест**, 80 карточек с управлением стрелками на клавиатуре.
3. Перетащите собственный EPUB, TXT или SRT на страницу. Откройте текст в рейтинге. Нажатие на слово позволяет отметить его знакомым, незнакомым или исключённым, после чего библиотека пересчитывается.
4. В разделе **Что выучить** выберите размер подборки. У каждого слова есть пример и накопленная доля понятных предложений. **Экспорт в Anki → Скачать CSV** сохраняет словоформу, лемму, пример и источник. Если осталось меньше выбранного числа незнакомых слов, выгружаются все оставшиеся.
5. Сохраните резервную копию в **Настройках**. Изменения числа знакомых слов и тексты, достигшие покрытия 98%, видны на странице **Мой словарь**.

В Anki экспортируйте выбранные заметки как **Notes in Plain Text**. Запрос `deck:"Название" -is:new` отберёт уже показанные карточки. Импортированный список пополняет личный словарь, а повторный тест обновляет его оценочную часть. Ручные отметки сохраняются.

## Как читать результаты

- **Покрытие слов** учитывает каждое употребление, включая повторы. Метки «можно читать», «с усилием» и «пока рано» соответствуют границам 98% и 95%.
- **Понятно целиком** показывает долю предложений без незнакомых лемм. В SRT одно предложение для расчёта — один блок субтитров.
- **+1 слово** показывает долю предложений с ровно одной незнакомой леммой. При подборе очередного слова алгоритм пересчитывает, сколько предложений оно откроет вместе с предыдущими.

Грамматика, идиомы и фразовые глаголы могут затруднять чтение даже при высоком покрытии. Тест словаря даёт начальную оценку по частотным диапазонам. Табличный лемматизатор правильно обработал 240 из 246 форм на размеченной выборке. Омонимы, имена и контекстные значения остаются источником ошибок. Сравнение оценок приложения с впечатлениями читателей требует пользовательского исследования. ## Сборка из исходников

Требуются Node.js 22.13+ и pnpm 10. Версия менеджера пакетов указана в `package.json`. Языковые данные включены в репозиторий.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm build` создаёт статическое приложение в `dist/`. `pnpm preview` запускает предварительный просмотр. Для GitHub Pages выбирается **Settings → Pages → Source → GitHub Actions**. Workflow деплоя размещает сборку ветки `main`.

| Каталог | Содержимое |
| --- | --- |
| `apps/web` | Интерфейс Svelte, Web Worker с Comlink, хранение в IndexedDB через Dexie |
| `packages/core` | Разбор EPUB, TXT, SRT и словарей, метрики, выбор слов, экспорт CSV |
| `packages/lang-en` | Английская морфология, частотные диапазоны, тест словаря, сборщик данных |
| `data` | Снимки языковых данных, литературные тексты и лицензии |
| `tests/e2e` | Браузерные сценарии Playwright и проверки доступности |

## Проверки

```sh
pnpm check
pnpm lint
pnpm test
pnpm build
pnpm size
pnpm exec playwright install chromium
pnpm test:e2e
pnpm --filter @coverage/core bench
```

На локальной машине с Node 22.16 разбор и подсчёт метрик для текста в 100 тысяч токенов заняли в среднем 82 мс, подбор 40 слов — 3 мс. Замеры чистого ядра исключают запись в IndexedDB и отрисовку. Проверка размера отдельно измеряет основной JavaScript и модуль анализа вместе с данными.

## Приватность и лицензии

Сайт отдаёт статику. Парсеры работают в Web Worker, шрифты и иллюстрации загружаются с того же сайта. Аккаунт и аналитика в приложении отсутствуют. Поддерживаются файлы текстов до 24 МиБ и до миллиона слов. Архив EPUB проверяется до и во время распаковки.

Код распространяется под MIT. Наборы языковых данных, тексты, иллюстрации и шрифты имеют собственные условия.
