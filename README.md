# Coverage Finder

Выберите английскую книгу или сериал под свой словарь. Coverage Finder покажет, какие предложения уже можно прочитать целиком и какие слова помогут понять больше. Для первой пробы не нужны регистрация, свой словарь или файлы: в библиотеке уже есть 14 демотекстов.

**[Открыть демо в браузере](https://charlz-ferra.github.io/coverage-finder/)** · [Скачать для офлайн-чтения (.zip)](downloads/Coverage-Finder.zip?raw=true) · [Помощь](docs/reader-guide.md) · [Для разработчиков](docs/development.md)

## Как открыть

**Без установки, в том числе на телефоне:** откройте [веб-версию](https://charlz-ferra.github.io/coverage-finder/). Для работы без интернета скачайте готовую сборку:

1. Скачайте ZIP по ссылке выше и **распакуйте его целиком**. Кнопка GitHub **Code → Download ZIP** скачивает исходники, а не готовое приложение.
2. Для локального запуска нужен [Python 3](https://www.python.org/downloads/). В **Windows** дважды щёлкните `Open-Coverage-Finder.cmd`. В **macOS/Linux** откройте терминал в распакованной папке и выполните `python3 scripts/open-library.py`. Устанавливать Node.js или собирать проект не нужно.
3. Библиотека откроется в браузере по адресу `http://127.0.0.1:8765/`. Оставьте окно запуска открытым, пока читаете. Интернет для работы скачанной библиотеки не нужен.

## Попробуйте на двух книгах

Откройте **План слов**, отметьте *Alice’s Adventures in Wonderland* и *The Wonderful Wizard of Oz*, оставьте **20 слов** и нажмите **Составить план**. Раскройте слово, чтобы увидеть предложение и книгу, из которой взят пример.

| Для демо-словаря из 3 000 лемм | Понятно сейчас | Если выучить подборку |
| --- | ---: | ---: |
| Обычный план, с именами персонажей | 42 из 113 | 70 из 113 (+28 предложений) |
| Включено «Пропускать вероятные имена» | 42 из 113 | 65 из 113 (+23 предложения) |

Во втором плане вместо имён встретятся `dreamy`, `gaunt` и другие слова. Пропуск имени не добавляет его в словарь и сам по себе не делает предложение понятным. [Сравнить все 20 карточек](docs/demo-study-plan.md).

## Перейти к своей книге

- **Загрузить словарь** принимает TXT, CSV и текстовый экспорт Anki. Если списка нет, выберите **Пройти тест**. **Добавить текст** принимает английские EPUB без DRM, TXT и субтитры SRT.
- В книге нажмите на слово, чтобы отметить его знакомым или незнакомым. Для нескольких текстов откройте **План слов → Скачать CSV для Anki**. CSV содержит слова, примеры и источники в порядке подборки.
- Книги и словарь остаются в этом браузере. Перед очисткой данных или переходом на другой компьютер выберите **Настройки → Скачать JSON**. На новом устройстве используйте **Выбрать JSON**.
