# Как пользоваться Coverage Finder

[Открыть приложение](https://charlz-ferra.github.io/coverage-finder/) · [Вернуться на главную](../README.md) · [Скачать готовую сборку](../downloads/Coverage-Finder.zip?raw=true)

## Начать без своих файлов

При первом запуске в библиотеке есть 14 английских текстов. Пока вы не добавили свой словарь, приложение предполагает, что вам знакомы 3 000 частотных слов. Откройте книгу в каталоге: цвет подскажет, какие слова стоит повторить. Нажмите слово, если хотите изменить его статус.

**Покрытие слов** учитывает повторы. **Понятно целиком** — доля предложений без незнакомых слов. В субтитрах вместо предложения считается один блок реплик. Это прогноз по лексике, а не оценка понимания грамматики или сюжета.

## Добавить свои слова и тексты

- Выберите **Загрузить словарь**, укажите CSV или TXT и проверьте в предпросмотре, какая колонка содержит английское слово. Для Anki подойдёт экспорт **Notes in Plain Text**. Запрос `deck:"Название" -is:new` отберёт карточки, которые вам уже показывали.
- Если списка нет, нажмите **Пройти тест**: по 80 карточкам приложение оценит ваш словарь. Это приближение; отдельные слова можно исправить вручную.
- Через **Добавить текст** выберите английскую книгу EPUB без DRM, обычный TXT или субтитры SRT. Файл можно перетащить на страницу. Ограничения на один файл — 24 МиБ и миллион слов. Импортированные тексты и словарь не отправляются на сервер.

## Читать и собирать карточки

В книге откройте **Что выучить**, а для нескольких книг или эпизодов — **План слов**. Отметьте хотя бы два текста, выберите размер подборки и нажмите **Составить план**. Раскройте слово, чтобы увидеть форму из текста, пример и источник. Если кандидатов меньше заданного числа, карточек тоже будет меньше.

**Пропускать вероятные имена** действует только в этом плане. Пропуск не делает имя знакомым. Кнопка **Не учитывать**, напротив, меняет расчёт для всей библиотеки. Если вы ранее отметили имя как незнакомое, эта отметка важнее автоматического фильтра.

**Скачать CSV для Anki** в плане сохраняет показанные карточки в порядке изучения. В Anki при импорте сопоставьте четыре колонки: `Word` — форма из текста, `Lemma` — словарная форма, `Example` — предложение, `Source` — источник. Ссылка **Посмотреть CSV** позволяет проверить содержимое до скачивания.

На телефоне в книге есть вкладки **Читать** и **Что выучить**. Библиотека запоминает страницу и размер шрифта; кнопка **Продолжить чтение** возвращает к последнему тексту. Клавиша `/` в каталоге переводит фокус в поиск.

## Где лежат мои данные?

В хранилище того браузера и адреса, в котором вы открыли приложение. Локальный запуск использует `http://127.0.0.1:8765/`. У размещённого сайта, другого порта, профиля или браузера будет отдельная библиотека. В приватном окне данные могут исчезнуть после закрытия.

**Настройки → Скачать JSON** сохраняет тексты, словарь, план, историю и места чтения. На другом устройстве откройте **Настройки → Выбрать JSON**. Восстановление заменяет текущую библиотеку — сначала сохраните её копию, если она нужна. CSV для Anki не заменяет резервную копию.

## Если что-то не работает

| Что видите | Что сделать |
| --- | --- |
| В папке нет `dist` или приложение просит `pnpm build` | Вы скачали исходники. Распакуйте [готовый ZIP](../downloads/Coverage-Finder.zip?raw=true) целиком. |
| Запуск сообщает, что Python не найден | Установите [Python 3](https://www.python.org/downloads/) и снова откройте лаунчер. |
| После двойного щелчка по `index.html` библиотека не открывается | Запустите `Open-Coverage-Finder.cmd` в Windows или `python3 scripts/open-library.py` в macOS/Linux. Откройте адрес из окна запуска. |
| Библиотека кажется пустой после обновления | Проверьте браузер, профиль и адрес. Если они изменились, перенесите JSON-копию. Не очищайте данные сайта, пока не сохранили копию. |
| Хочу сообщить об ошибке | На GitHub выберите **Issues → New issue**. Укажите браузер, формат файла и шаги. Короткого вымышленного примера достаточно; не прикладывайте личный словарь, полную книгу или резервную копию. |
