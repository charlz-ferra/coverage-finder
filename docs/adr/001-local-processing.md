# 001. Обработка в браузере

Принято для английского MVP.

Читатель загружает собственные книги, субтитры и выгрузку словаря. Для расчёта достаточно содержимого файла, набора лемм и статического языкового пакета. Серверная обработка потребовала бы передачи этих данных.

Статический хостинг отдаёт приложение, данные языка и демо-библиотеку. Страница передаёт импортированные файлы в Web Worker через Comlink. В фоне ядро извлекает текст и считает показатели. Dexie сохраняет разобранные единицы, словарь и результаты в IndexedDB этого сайта. Хеш содержимого предотвращает повторный импорт того же файла. [Worker](../../apps/web/src/lib/worker.ts) · [Хранилище](../../apps/web/src/lib/storage.ts)

При смене адреса сайта, браузера или устройства потребуется перенос данных. Пользователь может скачать резервную копию JSON и восстановить её в новом профиле. Очистка данных сайта в браузере удаляет локальную библиотеку. [Резервные копии](../../apps/web/src/lib/backup.ts)
