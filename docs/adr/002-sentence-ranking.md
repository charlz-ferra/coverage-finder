# 002. Сортировка по доле полностью знакомых предложений

Принято для английского MVP.

У двух текстов может быть одинаковое покрытие слов. Если незнакомые слова сосредоточены в одном длинном описании, читатель сможет пройти несколько страниц подряд. Если они разбросаны между короткими репликами, паузы понадобятся чаще.

Рейтинг по умолчанию сортирует тексты по доле единиц со всеми знакомыми словами. Для книги единица соответствует предложению, для SRT — блоку субтитров. Покрытие слов определяет метку готовности, а доля единиц с одной новой леммой показывает, сколько контекстов пригодно для пополнения словаря. [Показатели и пример](../methodology.md)

Длина предложений влияет на этот порядок. Тексты с короткими фразами часто окажутся выше. Пользователь может переключить сортировку на покрытие или длину текста и проверить спорный результат по выделенным словам в оригинале.
