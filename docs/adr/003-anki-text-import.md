# 003. Импорт словаря из текстовой выгрузки Anki

Принято для английского MVP.

В колоде Anki могут одновременно находиться выученные, новые и приостановленные карточки. Выбор изученных карточек в обозревателе Anki даёт пользователю контроль над исходным набором. Запрос `deck:"Название" -is:new` исключает новые карточки. Запрос `deck:"Название" prop:ivl>=21` выбирает карточки с интервалом повторения от 21 дня.

Выбранные записи экспортируются через **Notes in Plain Text**. Приложение распознаёт табуляцию, запятую и точку с запятой, показывает первые строки и позволяет выбрать колонку. При импорте убираются HTML и ссылки на звук. Для карточек с пропусками берётся ответ внутри разметки cloze. Обычные ячейки с целым предложением пропускаются. Извлечённые слова проходят тот же разбор, что и текст книги. [Парсер](../../packages/core/src/vocabulary.ts) · [Экспорт в Anki](https://docs.ankiweb.net/exporting.html)

Такой обмен добавляет ручной шаг в Anki и поддерживает списки из других источников. Прямая загрузка `.apkg` потребует чтения разных версий базы, учёта расписания повторений и отдельных тестов на формат колоды. Её имеет смысл пересмотреть, если текстовый экспорт окажется препятствием для пользователей.
